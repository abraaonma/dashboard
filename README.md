Repository Dashboards

The dashboards in this repository were developed to be useful for the development of systems that require the use of dashboards.

However, although there are existing standards in the market, I tried to build them by varying the perspective of utility—that is, by modifying colors, icons, and shapes, making extensive use of PHP with a bit of JavaScript.

Those who need to use these dashboards should know that they serve only as a 'shell' for data display and, therefore, were designed with code economy in mind.
